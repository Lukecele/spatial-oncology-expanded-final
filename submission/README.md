# Exploratory Preprint Submission Package

This directory contains the aligned exploratory preprint package for the
Spatial Continuum Translational project.

- `manuscript_full.md`: authoritative manuscript source.
- `manuscript_full.docx` and `manuscript_full.pdf`: rendered submission files.
- `figures/`: manuscript and supplementary figures. Legacy figures with
	superseded sanctuary or interventional-trial wording are retained only in
	`figures/archive_legacy/` and are not part of the submission evidence set.
- `software_strumenti_calcolo/cri_calc.py`: deterministic research-only CRI calculator.
- `tests/test_cri_calc_research.py`: focused calculator tests.
- `cover_letter_springer_nature.md`: cover-letter draft.

The package is exploratory and does not provide a clinically validated score,
treatment recommendation, or independent reanalysis of every contextual cohort.
The repository root retains the translational analysis code and datasets.
